# FAQ

**Is this the same game as Chapel of Dreams?** No - it is game 1 of the trilogy (top-down, ALttP-style); Chapel is game 2 (side-view, SotN-style). They share Joe, the cast, the lore and the code foundations.

**Why 384x216 and not ALttP's 256x224?** The owner chose the same 16:9 framing as Chapel so the trilogy looks consistent on modern screens.

**Where did the old prototype go?** It is in git history (up to `cec47ca`).

**Why is the art generated by code?** One palette, reproducible art, and no hand-edited files drifting from their source - the method that worked for Chapel.
