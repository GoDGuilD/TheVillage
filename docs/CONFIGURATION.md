# Configuration

| Where | What |
|---|---|
| `project.godot` | 384x216 viewport, integer scaling, autoloads (GameState, Audio, Juice), input map (keyboard + SNES-layout gamepad), physics layer names, renderer |
| `src/player/PlayerTuning.gd` | Every feel number for Joe (walk, nudge, sword box, charge/spin, shield cone, lift/throw, hurt, i-frames, health) |
| Enemy scripts (`src/enemies/*.gd`) | Each enemy's speeds, ranges and timings as constants at the top; HP/damage in `_init()` |
| `src/core/GameState.gd` | Drop table weights and gem values |
| `tools/palette.py` | Every colour of the generated art |
| `assets/tiles/overworld_light.json` | Tile names and solidity (generated by `tools/gen_tiles.py`) |
| `assets/sprites/joe/joe_animations.json` | Joe's frame size, feet point, fps, loop flags, slash hit window (generated) |

No environment variables or secrets are used. Player settings (volume, language) will be saved to the user data folder from Phase 4.
