# Configuration

| Where | What |
|---|---|
| `project.godot` | 384x216 viewport, integer scaling, autoloads (GameState, Audio, Juice), input map (keyboard + SNES-layout gamepad), physics layer names, renderer |
| `src/player/PlayerTuning.gd` | Every feel number for Joe (walk, nudge, sword box, charge/spin, shield cone, lift/throw, hurt, i-frames, health) |
| Enemy scripts (`src/enemies/*.gd`) | Each enemy's speeds, ranges and timings as constants at the top; HP/damage in `_init()` |
| `src/core/GameState.gd` | Drop table weights, gem values, magic/key/bomb/arrow limits, pieces per heart, item-menu order |
| `src/world/World.gd` | Scroll time and push, door fade time, Game Over delay, dialogue box placement threshold |
| `src/items/ItemDB.gd` | Item names/icons/texts, lantern and fire rod magic costs, Boni's wares (amounts, prices, one-time) |
| `src/items/Boomerang.gd`, `Arrow.gd`, `Bomb.gd`, `ItemUse.gd` | Range and speeds, arrow damage, fuse and blast radius/damage, bombs at once |
| `tools/gen_areas.py` (`D1`, `d1_rooms()`) | The Moss Shrine: rooms, doors, keys, switches, the boss room |
| `src/enemies/GrandSlime.gd` | Boss HP, hop speed/time, rest times, minion cap |
| `src/enemies/IronRam.gd`, `FrostWraith.gd`, `CaverShade.gd`, `Bat.gd` | Act 1 bosses and the bat: speeds, timings, HP |
| `tools/gen_areas.py` (`D2`, `D3`, `KEEP`, `d2_rooms()`, `d3_rooms()`, `keep_rooms()`, `build_south_fields`) | Act 1's places |
| `src/world/World.gd` (dungeons) | 40 px dungeon push, boss reward delay, reward positions |
| `tools/gen_areas.py` (`DARK_NAMES`, `DARK_EDITS`, `DARK_EXTRA`, `ACT2_SPAWN`) | The Dark World twins |
| `tools/gen_dark.py` (`MAP`, `HUE_*`, `SAT_KEEP`, `VALUE_KEEP`) | How the Dark World is recoloured |
| `src/world/World.gd` (`DW_TINT`, `DW_HP_FACTOR`, `WORLD_FADE`) | Dark World tint, enemy toughness, warp fade |
| `src/items/Grapple.gd` (`SPEED`, `RETURN_SPEED`, `RANGE`, `LATCH_RADIUS`), `PlayerTuning` (`PULL_SPEED`, `PULL_MAX`) | The grapple's reach and speeds |
| `tools/gen_umbra.py` (`LIGHT_SMALL`, `LIGHT_LANTERN`, `SOFT`) | How much Joe sees in a dark room (with and without the lantern) |
| `src/enemies/Lurker.gd`, `GloomMoth.gd` | Lurker speed and "looked at" cone; the moth's loop, dust, ground time |
| `tools/gen_areas.py` (`D4`, `d4_rooms()`, `build_umbra_vale`, `DARK_ONLY`), `ItemDB.WARES` (`dw_*`) | Umbra's places and the Shade Market's prices |
| `src/ui/UiTheme.gd` | UI colours, overlay tints, CanvasLayer order |
| `src/ui/DialogueBox.gd` | Text speed, blip rate, box size and positions |
| `assets/data/dialogue.json` | Every villager line and sign text |
| `src/core/SaveGame.gd` | Save path (`user://village_save.json`; on Windows `%APPDATA%\Godot\app_userdata\The Village\`) and format version |
| `tools/gen_areas.py` | The world itself: screen size, area list and positions, every area's layout, interiors |
| `tools/palette.py` | Every colour of the generated art |
| `assets/tiles/overworld_light.json` | Tile names and solidity (generated by `tools/gen_tiles.py`) |
| `assets/sprites/joe/joe_animations.json` | Joe's frame size, feet point, fps, loop flags, slash hit window (generated) |

No environment variables or secrets are used. Player settings (volume, language) will be saved next to the save file from Phase 14.
