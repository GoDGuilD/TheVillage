# Bugs and gotchas

- [Internal] **Tools folder became a file** - Symptom: `tools/palette.py` could not be written (ENOENT). Root cause: Windows paths are case-insensitive; `mkdir tools` was a no-op while the old `Tools/` existed, the old folder was then deleted, and `cp sprite_lib.py tools/` created a *file* named `tools`. Fix: recreated the folder. File: `tools/`.
- [External] **Input press seen one frame late in tests** - Symptom: state still `idle` one frame after `Input.action_press("attack")`. Root cause: Godot flushes action presses into `is_action_just_pressed` on the next physics frame. Workaround: tests wait 2 frames. File: `tests/test_player.gd`.
- [Internal] **Method named `_set` in TestField** - Symptom: would override `Object._set` (property setter virtual). Fix: renamed to `_put_tile`. File: `src/world/TestField.gd`.
- [Internal] **Leaf burst invisible against grass** - Symptom: cut bushes seemed to vanish. Root cause: green leaves with no outline on green grass. Fix: outlined leaf frames + a test that the burst plays. File: `tools/gen_tiles.py`.
- [External] **A new `class_name` hangs the headless suites until `--import`** - Symptom: after adding `AreaBuilder`, the test run never finished (no output, no exit). Root cause: Godot's global class cache is only refreshed by an import/editor pass; scripts naming the new class fail to compile and the `-s` script waits forever. Workaround: run `--headless --path . --import` after adding a `class_name`, and wrap test runs in `timeout`. File: `tests/*`.
- [Internal] **Grass lip across roads at area edges** - Symptom: a thin grass line across the road exactly where two areas meet (seen mid-scroll). Root cause: the nine-slice autotiler treated cells outside the area as "not road". Fix: off-area neighbours count as the same terrain (`AreaBuilder._differs`, and the preview renderer). File: `src/world/AreaBuilder.gd`, `tools/gen_areas.py`.
- [External] **`round()` breaks typed variables** - Symptom: every suite failed to compile with "The variable type is being inferred from a Variant value" at `Hud.gd:171`. Root cause: in Godot 4 the global `round()` returns a Variant, and this project treats inference warnings as errors. Fix: use `roundf()` (or `Vector2.round()`) wherever the result feeds a `:=` variable. File: `src/ui/Hud.gd`, `DialogueBox.gd`, `TitleScreen.gd`.
- [External] **A test naming an autoload-using class fails to compile** - Symptom: `test_ui.gd` failed with "Identifier not found: Audio" in `PauseMenu.gd`, which cascaded into a half-built World (no pause menu, no fade) and 13 failures. Root cause: in `-s` mode the test script is compiled before autoloads are registered, so any class it names statically (`PauseMenu.ITEM_SAVE`) must compile without them. Fix: read the constant through the instance (`world.pause_menu.ITEM_SAVE`). File: `tests/test_ui.gd`.
- [Internal] **Villager lint accepted Joe standing two tiles away** - Symptom: a villager boxed in by rocks still passed the lint (found by a deliberate mutation). Root cause: the counter rule (talk from two tiles away) was applied to every villager in every direction, so a reachable cell beyond a wall counted. Fix: only villagers marked `across` get the two-tile reach, and only along their facing. File: `tools/gen_areas.py`.
- [External] **A member named `hidden` breaks any CanvasItem script** - Symptom: "Member 'hidden' redefined (original in native class 'StaticBody2D')" and every script depending on `Chest` failed to compile. Root cause: CanvasItem already has a `hidden` signal. Fix: the chest's flag is `concealed`. File: `src/world/Chest.gd`.
- [External] **`Array.filter()` result cannot be inferred** - Symptom: World.gd failed to parse ("Cannot infer the type of 'torches'"), which hung the headless world suite. Root cause: `filter()` returns an untyped Array; `:=` needs a known type (warnings are errors here). Fix: declare `var torches: Array = ...`. File: `src/world/World.gd`.
- [Internal] **`HurtBox.recheck()` errored with monitoring off** - Symptom: "Can't find overlapping areas when monitoring is off" when Joe's i-frames ended in tests and captures (hurt box switched off). Root cause: `recheck()` called `get_overlapping_areas()` unconditionally. Fix: return early while `monitoring` is false. File: `src/combat/HurtBox.gd`.
- [Internal] **A member variable named like a method breaks the class** - Symptom: "Could not parse global class 'Chest'" and every script using Chest/BigChest failed. Root cause: Chest got a `reveal` variable next to its `reveal()` method. Fix: the variable is `reveal_by`. File: `src/world/Chest.gd`.
- [External] **A tweened static body did not trigger an Area2D switch** - Symptom: the push block slid across the heavy floor switch without pressing it (headless runs). Root cause: overlap reporting between an Area2D and a StaticBody2D teleported by a tween is not reliable frame to frame. Fix: the block presses any switch it comes to rest on directly (group `floor_switch`, distance check). File: `src/world/PushBlock.gd`.
- [Internal] **The family seal was grabbed the instant it appeared** - Symptom: after the heart container the seal's moment was skipped. Root cause: the seal spawned on the container's spot, where Joe was standing. Fix: it appears 32 px higher (`SEAL_DROP`). File: `src/world/World.gd`.
- [Internal] **The seal gate could not be talked to** - Symptom: pressing interact in front of the keep's gate did nothing. Root cause: the 32-px gate's talk point sat 8 px below its centre, more than Joe's one-tile probe radius away from where he stands (in front of either half). Fix: the talk point is 2 px below the centre. File: `src/world/SealGate.gd`.
- [External] **Static class names in a test compile before the autoloads** - Symptom: `test_act1.gd` failed with "Identifier not found: Audio" in Bush/IronRam and the whole World half-built. Root cause: `is IronRam` and `AreaBuilder.flag_at` in the test compile those classes (and their dependencies) before autoloads exist. Fix: compare `get_script().get_global_name()` and `load()` AreaBuilder. File: `tests/test_act1.gd`.

- [Internal] **Floor switches (and rifts) were invisible** - Symptom: the Moss Shrine's floor switch never showed in screenshots; the first rift did not either. Root cause: they set `z_index = -1` to sit "under" actors, which also put them under the ground TileMapLayer. Fix: leave z at 0 and let the y-sorted actors node order them. File: `src/world/FloorSwitch.gd`, `src/world/Rift.gd`.
- [Internal] **Accents on capitals could not be seen** - Symptom: MÚSICA, ESPAÑOL read as MUSICA, ESPANOL in game. Root cause: the 5x7 capitals fill 7 of the cell's 8 rows, so the mark sat on row 0 touching the shortened letter and vanished at 1x. Fix: a free row between mark and letter; the accented capital sits one pixel lower. File: `tools/gen_ui.py`.
- [External] **Autoloads are not ready in a `-s` script's `_initialize`** - Symptom: the Music and SFX buses were missing and `Audio`'s players array was empty in `test_polish.gd`. Root cause: in a `-s` run the autoloads enter the tree (and run `_ready`) after `_initialize` starts. Fix: `await process_frame` before using them. File: `tests/test_polish.gd`.
- [External] **A resting gamepad trigger claimed "gamepad"** - Symptom: in a windowed capture the end card said PULSA B although the keyboard was in use. Root cause: some pads report a trigger axis at full deflection when idle, which passed the "stick moved" test. Fix: only the four stick axes count. File: `src/core/InputHints.gd`.
- [Internal] **The music composer read "b7" as a seventh** - Symptom: `ValueError` on "b7" chords. Root cause: a "7" suffix meant "seventh chord", so the degree itself was stripped; borrowed chords were also built from the mode's own degree. Fix: no seventh suffix; borrowed chords are fixed offsets from the major scale, and the melody's chord tones may be chromatic. File: `tools/gen_music.py`.
- [Internal] **No gamepad button backed out of menus; two buttons were documented wrong** - Symptom: menus could be confirmed with a pad (interact) but not left; the controls table said inventory = left shoulder and dash = right stick. Root cause: `ui_cancel` had no joypad event; the table predated the input map. Fix: East confirms, South goes back (`ui_accept`/`ui_cancel`), dash on both shoulders, table corrected. Files: `project.godot`, `docs/GDD.md`.
- [Internal] **Player settings would leak into test runs** - Symptom (prevented): a player who chose Spanish or muted the music would make every suite run that way. Fix: `Audio` reads the settings file only when the main loop has no script (never under `-s`). File: `src/core/Audio.gd`.
- [External] **`gen_ui.py` redraws `icon_sword.png`** - Symptom: running the unchanged UI generator changes the sword icon's pixels. Root cause: the same Pillow rasterisation drift as `gen_joe.py`. Workaround: restore it with `git checkout` after running. File: `tools/gen_ui.py`.
- [Internal] **Crust timers errored after leaving the room** - Symptom: "Lambda capture at index 2 was freed" printed once per frozen lava cell when Joe left a room less than 6 s after using the ice rod. Root cause: the thaw callback of `AreaBuilder.freeze_at` captured the room's `TileMapLayer`, which is freed when Joe leaves; calling a lambda with a freed capture errors. Fix: the callback holds a `WeakRef` and skips a freed layer. File: `src/world/AreaBuilder.gd`.
- [External] **`weakref()` cannot be type-inferred** - Symptom: "The variable type is being inferred from a Variant value" parse error (warnings are errors) on `var r := weakref(x)`, and on `var t := r.get_ref() as TileMapLayer`. Root cause: both return Variant in GDScript. Fix: declare the types (`var r: WeakRef = weakref(x)`, `var t: TileMapLayer = ...`). File: `src/world/AreaBuilder.gd`.
- [Internal] **The Dark World map ran off its panel** - Symptom: the map's bottom rows fell outside the panel and area names overlapped in narrow boxes. Root cause: the map drew every screen at a fixed 40x24 box; the Dark World grew to seven screens tall (Umbral Vale), and Caver's tower is six rooms tall. Fix: boxes shrink (each axis separately) to fit; names wrap onto two lines. File: `src/ui/MapScreen.gd`.
- [Internal] **A boss's shots outlived it** - Symptom: bolts kept flying after Caver fell and could hit Joe while the ending began. Root cause: only the boss's brood (enemies) was freed on its defeat. Fix: `_on_boss_defeated` also frees enemy shots and orbs. File: `src/world/World.gd`.
- [Internal] **Dark World bosses got angry at a quarter of their health** - Symptom: the Gloom Moth, the Magma Wyrm and the Clock Warden only sped up near death in the Dark World. Root cause: their "below half health" test compared with `max_hp`, the stat before the World doubles Dark World health. Fix: compare with `health.max_health`. Files: `src/enemies/GloomMoth.gd`, `MagmaWyrm.gd`, `ClockWarden.gd`.
- [Internal] **BOOTS overlapped HEART PIECES in the item menu** - Symptom: the boots' label ran into the heart pieces title. Root cause: the equipment list grew downward (row 4) into the bottom section. Fix: a second equipment column for the boots and the flippers. File: `src/ui/ItemMenu.gd`.
- [External] **Regenerating Joe redraws the sword strips** - Symptom: running the unchanged `gen_joe.py` rewrites `joe_attack_*`, `joe_charge_*` and `joe_spin` with small pixel differences. Root cause: not confirmed; the generator has not changed since Phase 2, so the likely cause is a Pillow update changing how lines or polygons are rasterised. Workaround: after running it, restore the strips you did not mean to change (`git checkout`). File: `tools/gen_joe.py`.
- [Internal] **A test ran before the previous scroll had finished** - Symptom: in `test_tempus.gd` Joe walked into molten time and never fell, ending at the area's edge. Root cause: the way-in test waited a fixed number of frames; the scroll was still sliding, and its end reset Joe's position and entry point after the next test had already moved him. Fix: wait for `World.transitioning` to clear. File: `tests/test_tempus.gd`.
- [Internal] **Ignis tiles would have redrawn the shrine** - Symptom: (caught before shipping) adding the lava cells to `gen_tiles.py` shifted the shared random stream, so every cell drawn after them (the Moss Shrine facade) would change. Root cause: one `random.Random` feeds the whole atlas in order. Fix: the Ignis cells use their own seeded stream; a cell-by-cell diff against the previous atlas showed no old cell changed. File: `tools/gen_tiles.py`.
- [External] **A test naming AreaBuilder / BaseEnemy does not compile** - Symptom: `test_ignis.gd` failed with "Identifier not found: Audio", and later area builds failed oddly. Root cause: the same as before - in `-s` mode a static reference compiles those classes before the autoloads exist. Fix: `load()` AreaBuilder into a variable and read enemy constants through an instance. File: `tests/test_ignis.gd`.
- [External] **JSON numbers come back as floats** - Symptom: `test_umbra.gd` said the Umbral Vale was not at its origin although the data was right. Root cause: `JSON.parse_string` turns every number into a float, and `[0.0, -14.0] == [0, -14]` is false for Arrays. Fix: compare positions as `Vector2` (`World.origin_of`). File: `tests/test_umbra.gd`.
- [Internal] **Dialogue checks read a half-typed box** - Symptom: text checks failed with "The m" or "". Root cause: the box types its page; `visible_text()` right after opening shows only the first letters. Fix: the test waits ~2 s (`_text()`) before reading. File: `tests/test_umbra.gd`.
- [Internal] **The moth's dust drew both frames side by side** - Symptom: the first dust shot preview was a 20-px strip. Root cause: `EnemyShot` draws a plain Sprite2D, not an animation; the generator wrote a 2-frame strip. Fix: `dust_shot.png` is one frame. File: `tools/gen_umbra.py`.
- [Internal] **Tato's echo talked but gave nothing** - Symptom: the gift dialogue played, then no Moon Mirror. Root cause: `World.grant()` matches kinds explicitly and had no branch for `moon_mirror`. Fix: added it with the other passive/Y items. File: `src/world/World.gd`.
- [External] **Excluding `addons/` breaks the exported EXE's autoloads** - Symptom: the first export, with `addons/*` excluded, logged "Failed to instantiate an autoload ... mcp_runtime_probe.gd" at start. Root cause: the enabled `godot_mcp` editor plugin registers a runtime-probe autoload in the project settings while the editor runs, so the export carries it even though `project.godot` has no such autoload. Workaround: keep `addons/` in the export (the probe does nothing without a debugger). File: `export_presets.cfg`.
