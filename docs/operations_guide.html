The Village — Operations & Maintenance Guide

Author: Jose-Jorge HERNANDEZ · Parlee Conseiller, Inc. · Version 4.0.0 (2026-10-15)

1. System description

The Village is a single-player, offline, top-down action-adventure game (A Link to the Past style) built with Godot 4.7.2. It is game 1 of The Village trilogy. All art is generated by Python scripts from one colour palette; behaviour is verified by headless scripted test suites.

3. Start, stop, verify

  • Start: open the editor, import the project folder, press F5. The title screen opens; NEW GAME starts in Joe's house, CONTINUE loads the save.
  • Stop: close the game window (or F8 in the editor).
  • Verify: run the six test suites; each must end with 0 failed (314 checks today):
Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 60 --path . -s tests/test_player.gd
Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 60 --path . -s tests/test_combat.gd
Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 60 --path . -s tests/test_world.gd
Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 60 --path . -s tests/test_ui.gd
Godot_v4.7.2-stable_win64_console.exe --headless --fixed-fps 60 --path . -s tests/test_items.gd

4. Logs and monitoring

The game writes Godot's standard log to %APPDATA%\Godot\app_userdata\The Village\logs\godot.log. Test runs print PASS/FAIL lines and a final RESULT line to the console; compare the number of checks between runs, since a script error can skip checks without failing them.

The save file is %APPDATA%\Godot\app_userdata\The Village\village_save.json (plain JSON). Deleting it resets the game to a fresh start; the title screen then offers only NEW GAME.

6. Common troubleshooting

SymptomFix
"Failed loading resource" for a PNGRun the --import command above.
Screenshots black or missingCapture scripts must run windowed (no --headless).
A test fails right after a simulated key pressPresses register on the next physics frame; tests wait two frames.
"ObjectDB instances were leaked" at exitHarmless teardown warning.
CONTINUE is greyed outNo save file (or one from an older format): start a NEW GAME and save from the pause menu (Esc).
Every test suite fails to compile after a UI editLook for round() feeding a typed variable (use roundf()) or a test naming a menu class statically.
