# Contributing

1. Read `GDD.md`, `ROADMAP.md` and `ARCHITECTURE.md`.
2. Change generators in `tools/` or code in `src/`; never hand-edit generated PNGs or manifests.
3. Every touched file keeps its branding header (File, Description, Author, Company, Date, Last edit date, Version) and gets its version bumped.
4. Run the test suites (`TESTING.md`) and look at visual changes with a windowed capture.
5. Update `../CHANGELOG.md`, any stale doc, `BUGS.md` for gotchas and `technical_memory/technical_memory.ipynb` for decisions.
6. Commits are authored as Jose-Jorge HERNANDEZ.
